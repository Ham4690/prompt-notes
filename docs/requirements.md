# prompt-notes 要件定義

ブラウザ作業中にプロンプトの下書きや考えを気軽に書き留め、整理するためのノートアプリ。

## 1. 目的

- ブラウザで作業しながら、プロンプトの下書きや思考メモをすぐ書ける
- 書いたメモをタグ・検索・TODO一覧で後から整理できる
- 仕事の情報を扱うため、メモの内容は端末の外に一切出さない

## 2. 前提・構成

| 項目 | 内容 |
|---|---|
| 配信 | GitHub Pages（静的サイト） |
| 利用形態 | PWAとしてインストールし、Chromeの横に別ウィンドウで並べて使う |
| データ保存 | ブラウザ内（IndexedDB）のみ |
| 外部通信 | アプリ本体の読み込み以外なし（メモ内容は一切送信しない） |
| 対象ブラウザ | Chrome |
| 端末 | 1台（同期なし） |
| 費用 | 無料 |

## 3. 機能要件

| # | 機能 | 内容 |
|---|---|---|
| F1 | 即書き | 起動時に入力欄へ自動フォーカス。ショートカットで新規メモ。タイトル・タグは後付けでよい（1行目をタイトルとして自動採用） |
| F2 | 編集 | Markdown、コードブロック、チェックリスト（`- [ ]`）。編集／プレビューの切り替え |
| F3 | コピー | メモ全体、およびコードブロック単位でワンクリックコピー |
| F4 | タグ | 本文中の `#タグ` 記法から自動抽出。タグで絞り込み |
| F5 | 全文検索 | タイトル・本文を対象に日本語で検索できる |
| F6 | TODO一覧 | 全メモ横断で未完了チェックを集約表示。チェックの切り替えと元メモへのジャンプ |
| F7 | バックアップ | Markdownでのエクスポート（全メモ）／インポート |
| F8 | 自動保存 | 入力中に自動保存（保存ボタン不要） |

## 4. 非機能要件

| # | 項目 | 内容 |
|---|---|---|
| N1 | オフライン | Service Workerによりオフラインでも起動・編集できる |
| N2 | データ永続化 | `navigator.storage.persist()` を要求し、ブラウザによる自動削除を防ぐ |
| N3 | 保存領域の分離 | `ユーザー名.github.io` 配下の他ページと保存領域を共有するため、DB名はアプリ固有にする |
| N4 | セキュリティ | Markdownプレビューは必ずサニタイズする。外部CDN・解析タグ・外部フォントは使わない |
| N5 | 軽さ | 起動から入力開始まで体感で待ち時間がないこと |

## 5. スコープ外

同期、共有、ファイル添付、メモ間リンク、フォルダ等の階層整理

## 6. 設計メモ

- **日本語検索**: 一般的な全文検索ライブラリは空白区切りのため日本語に弱い。初期は「正規化（NFKC＋小文字化）した文字列の部分一致」で実装し、件数が増えて遅くなったらn-gram（2文字区切り）索引に切り替える
- **タグ記法**: `#タグ`（`#` の直後に空白なし）をタグとみなす。`# 見出し` やコードブロック内は対象外
- **ショートカット**: `Ctrl+N` はChromeが予約しているため、新規メモは `Alt+N`、検索は `Ctrl+K` とする
- **データモデル（案）**

```ts
type Note = {
  id: string;          // UUID
  body: string;        // Markdown本文
  title: string;       // 1行目から導出
  tags: string[];      // 本文の #タグ から導出
  createdAt: number;
  updatedAt: number;
};
```
